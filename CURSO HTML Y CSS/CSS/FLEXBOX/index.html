Flexbox: Los elementos que estan dentro de la caja, el contenido, a esos es el que se les aplica las propiedades. Caja Contenedora (caja flexbox)--> Flex Item (a estos son los que afectan las propiedades) podemos definir a que direccion apunta, arriba, abajo, los podemos mover. Flex es unidimensional Caja contenedora: flex elementos: item flexibles. Si definimos a los elementos por su padding (no se achica ni se agranda), dejan de ser flexibles, mejor le damos ancho y alto
